### Archaeopteryx
Archaeopteryx is a [Talos-like](https://www.siderolabs.com/talos-linux) API tool so like `talosctl` stuff but for my own FSDK image called [Microraptor](https://github.com/HuntedRaven7/Microraptor)! ### Microraptor
As I mentioned before [Microraptor](https://github.com/HuntedRaven7/Microraptor) is a FSDK base image but what is that? FSDK stands for [Free Desktop SDK](https://freedesktop-sdk.io/) it is what 90% of flatpaks are built off of so it is VERY minimal and amazing base to build off of for a server image, The point of this image is to be almost like Flatcar Linux and Talos Linux so I am using this purely for [k0s](https://k0sproject.io/) for the Kubernetes distribution which Archaeopteryx uses as well! I am using a lot of Buildstream for this if you want to learn more go to my blog post here! https://robin.tarxz.zip/blog/need-of-buildstream
